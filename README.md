# Pranay Sumit Singh — Portfolio

Responsive black-and-purple personal portfolio built with HTML, CSS, and JavaScript.

## Included
- Personal portrait image
- About, skills, project, education/NSS, and contact sections
- Sanghaat 2026 project link
- Certificate preview cards with original PDF links
- Responsive mobile navigation and scroll animations

## Publish using GitHub Pages
1. Upload all files and the `assets` folder to the root of your GitHub repository.
2. Open **Settings → Pages**.
3. Under Build and deployment, choose **Deploy from a branch**.
4. Choose branch `main` and folder `/ (root)`, then Save.
5. Wait for the public Pages URL to appear.

## Before publishing
- Confirm that the public email and social links are the ones you want to display.
- Check every certificate/project detail for accuracy.
- All certificate scans are linked as supplied; the 9-page scanned PDF includes college competition certificates and NSS participation certificates.
